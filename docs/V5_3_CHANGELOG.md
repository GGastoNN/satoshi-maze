# Satoshi Maze V5.3 — Android Back Navigation

- Android system Back no longer closes the game automatically.
- Back now follows the in-game navigation hierarchy.
- Main menu Back opens a localized exit confirmation dialog.
- Back while the exit dialog is open cancels the dialog.
- Privacy/Terms return to Settings; purchases return to Store/Campaign; gameplay returns to its source screen.
- Payment, save, maze gameplay and wall-impact systems are unchanged.
- App version: 5.3.0 (Android versionCode 8).
