# Satoshi Maze V5.4 — Mandatory Intro

- The ILLU ENTERTAINMENT / SATOSHI MAZE presentation can no longer be skipped.
- Touch, mouse and keyboard input are consumed while the presentation is playing.
- Android/system Back is ignored during the presentation.
- Removed the “Tap to continue” hint.
- Normal Back navigation becomes available only after the main menu appears.
- Payment, save-data and gameplay systems are unchanged.
